# MichaelOS visual theme

MichaelOS uses an executive-publication visual system with technical tooling beneath it. The information architecture, browser capability runtime, Navi agent, Agent CLI, Action Keys, Inspector and persistence model are unchanged.

## Foundations

- Geist Sans is the interface and editorial typeface.
- Geist Mono is reserved for metadata, dates, commands, capability identifiers, tags and statuses.
- The main canvas is light grey; content sections use white surfaces and thin grey rules.
- Dark surfaces are reserved for Navi, the Agent Console, Capability Trace and command/data tools.
- Primary actions are black; secondary actions are white with a thin border.

## Highlight relevant

The sticky product toolbar exposes a persisted `Highlight relevant` view. The supported lenses are platform engineering, enterprise architecture, agentic AI, startup advisory, M&A integration, procurement and renewals, and customer ownership.

Matching projects, roles, writing, skills and CV evidence receive a soft-yellow background and dark left marker. Non-matching content remains comfortably readable. Lens matching is presentation-only and does not bypass or invoke the capability executor.

## Interaction feedback

Every shared capability execution immediately shows a validating/running status and then the canonical success or failure event. Project search has local searching and result-count feedback. Navi retains its pending message, browser execution status and Capability Trace.

## Responsive and accessible behaviour

The toolbar, publication indices, experience entries and CV sections collapse to a single column. Touch controls remain at least 44 pixels high, menus are bounded to the viewport, status text uses live regions, dropdown state uses `aria-expanded`, and reduced-motion preferences collapse all decorative transitions and animations.
